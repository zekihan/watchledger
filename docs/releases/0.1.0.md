# Watchledger 0.1.0

Initial public release of the self-hosted movie, TV and anime tracker. This is an early release with known acceptance gaps; publishing versioned artifacts does not close the remaining product checklist.

## Included

- Private PostgreSQL-backed libraries with OIDC login and separate admission/admin claims.
- Movie, TV and native anime metadata, episode tracking, personal ratings, custom statuses and source-aware alternate views.
- Manual and nested smart lists, Up next, calendar, statistics and English/Turkish screens.
- SIMKL import previews, conflict review and portable per-user export/restore.
- One application container serving the web interface, API, migrations and background jobs.

## Artifacts

Images support Linux amd64 and arm64:

```text
ghcr.io/zekihan/watchledger:0.1.0
docker.io/zekihan/watchledger:0.1.0
```

The OCI Helm chart is `oci://ghcr.io/zekihan/charts/watchledger`, version `0.1.0`, with application version `0.1.0`. The GitHub release also includes the chart archive and its SHA-256 checksum.

Follow the [deployment guide](https://github.com/zekihan/watchledger/blob/v0.1.0/docs/deployment.md). Provide external PostgreSQL, OIDC, a session encryption key and provider configuration. Back up the database before applying migrations or imports. No infrastructure deployment is performed by the release workflow.

## Known limitations

Physical Android installation/authentication and screen-reader acceptance, the real-provider authorization matrix, additional SIMKL account/import cases, and broader native anime/mixed-mapping coverage remain open. Real-provider Compose networking on the recorded Mac environment also remains unresolved. Ambiguous editions remain unresolved rather than silently merging history. See [operator checks](https://github.com/zekihan/watchledger/blob/v0.1.0/TODO.md) and the [feature tracker](https://github.com/zekihan/watchledger/blob/v0.1.0/docs/features.md) for the complete remaining scope.

Backend/database/race tests and synthetic Chromium, Firefox and WebKit acceptance are release gates. These checks do not establish real-device, screen-reader or every configured-provider behavior.
