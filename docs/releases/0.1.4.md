# Watchledger 0.1.4

This release improves navigation and visual clarity across the home dashboard, title pages, calendar, statistics and settings.

## Changes

- Show posters and a compact, expandable Up next list with ordering controls on each card.
- Group tracking and season actions, move trailer links into title cards, and collapse linked episode views while keeping mapping review notices visible.
- Improve availability cards, calendar density, filter labels, statistics charts and dropdown spacing.
- Replace raw metadata-language and country codes with localized names and offer searchable, independently selectable streaming subscriptions. Rakuten Viki can be selected even when the country-specific provider list omits it; availability remains subject to TMDB and JustWatch coverage.

## Validation and upgrade

Local lint, tests and build passed, including 115 frontend tests. A PostgreSQL-backed Up next test covered native and projected poster selection. Browser, accessibility and real-provider acceptance remain incomplete; automated frontend tests do not establish visual or physical-device acceptance.

The dedicated linked-view page opens its controls directly. This release adds no database migration. The dashboard response adds an optional poster path; existing history, credentials and configuration are preserved. Preserve the existing session key and database volumes during upgrade.

## Artifacts

Both `ghcr.io/zekihan/watchledger:0.1.4` and `docker.io/zekihan/watchledger:0.1.4` support Linux amd64 and arm64. The OCI chart is `oci://ghcr.io/zekihan/charts/watchledger`, version `0.1.4`. The GitHub release includes the chart archive and its SHA-256 checksum.
