# Watchledger 0.1.2

SIMKL imports now prepare explicitly identified titles and seasons in resumable batches instead of treating an empty metadata cache as a reason to review every item.

## Changes

- Continue an uploaded preview or reprepare a previously applied archive without uploading its source file again, with visible metadata-preparation progress and cancellation.
- Inspect and approve regular TV episode proposals together using the explicit TMDB show ID and season/episode numbers. Approval is bound to the exact proposal version.
- Keep specials, native-anime mappings, missing or conflicting identities and ambiguous episodes in review. Preserve gaps, unknown watched dates, existing ratings and explicit unwatch decisions.
- Download a fresh per-user export as part of the import action and move focus to remaining review items afterward.
- Pause on provider outages and respect TMDB rate-limit cooldowns. Cached preparation resumes without refetching completed work.
- Avoid creating extra review entries for identical reimports. All source archives remain private and retained.

## Validation and upgrade

Lint, build, database-backed tests, 104 frontend tests, the full Go race suite and a desktop Chrome smoke test passed locally with synthetic data. These checks do not establish every real-provider or physical-device import case.

This release adds no database migration and does not change credentials, infrastructure or admission/admin policies. Preserve the existing session key and database volumes. Existing SIMKL previews and previously applied source archives can be prepared again from Settings without re-uploading. Reopening an archive changes no library or history data; applying still requires a backup and fresh explicit episode approval. Publishing or deploying this release does not apply an import automatically.
